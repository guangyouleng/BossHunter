# 招聘端稳定性复核（2026-10-19）

版本保持 2.4.2。本轮连续检查外发、暂停、任务恢复、前端控制，以及 Windows 构建/启动/停止/升级代码；未检查或修改求职端业务。

## 确认并修复

| 问题与触发条件 | 修复后的行为 | 验证 |
| --- | --- | --- |
| 标准招呼在读取岗位后发生切岗，或页面存在隐藏/重复候选卡片 | 实际点击脚本再次核实岗位，唯一定位可见卡片与按钮；无法确认时停止 | 本地 DOM 复现与定向回归 |
| CloakBrowser 定位后按钮被页面替换，原点击守卫未覆盖新按钮 | 只允许点击已核实的原按钮；替换、身份变化或新提示窗出现时阻止点击，不补点 | 本地 DOM 复现，实际隔离浏览器 iframe 复验 |
| 回复使用隐藏编辑器，或输入期间出现重复/替换的控件 | 两条输入路径核实唯一可见编辑器和发送控件；CloakBrowser 输入后、发送前及点击时继续核对，变化即停止并保留内容 | 实际隔离浏览器复现及 19 项交互回归 |
| HTTP 200 返回业务拒绝码，或消息/发送账号身份无法核实，只停止当前任务 | 进入共享冷却，停止监测与主动招呼；另一进程发送前也被拦截。诊断不保存平台响应正文 | 合成 HTTP、共享数据库及发送守卫测试 |
| Windows 复用进程号，将旧发送/租约误判为仍在执行 | 新任务同时记录进程创建时间；旧进程已结束则恢复为待核实，不自动重发。无法查询身份时不抢占活跃任务 | Windows API 模拟、任务恢复及跨进程租约测试；冻结程序增加本进程原生 API 自检 |
| 主动招呼启动前读取额度可能被长节流阻塞，前端不能及时停止 | 额度准备移入后台，启动接口及时返回；停止中断该招呼线程的额度等待，失败不进入招呼执行 | 有界后台线程与合成请求测试 |

此前同版本还修复了 Windows 关闭独立浏览器连带停止监测、启动取消后仍继续创建进程、Windows 换行误报待核实及绑定页面跳转后继续滚动的问题。

Windows 进程归属查询使用只读权限及 [GetProcessTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getprocesstimes)，不终止其他软件。旧版归属记录没有创建时间，不能追溯推断，继续兼容原有保守存活判断。

## 最终验证

- 招聘端、Windows 打包/启动器、配置及版本：537 项、50 项子测试通过；19 项需浏览器的测试在常规回归中跳过并另行执行。
- 桌面 CloakBrowser：19 项离线交互通过；最后修改的 iframe 招呼守卫另行复验通过。使用全新临时资料及本地合成页面，不访问 BOSS、不读取现有 Cookie、不外发消息。
- 前端：97 项通过，TypeScript 与生产构建通过。
- Browser Runtime/WS：23 项通过，HTTP/WS 原有监测和节流间隔保留。
- `git diff --check` 通过。

本轮审查范围内未发现仍未修复的重大代码缺陷。这不等同于所有系统、浏览器版本和真实平台场景均已验收。

## Windows 实机仍需确认

1. 用现有构建脚本生成 EXE 并通过冻结程序自检；本机没有 Windows 编译/安装环境。
2. 在目标 Windows 10/11 x64 电脑分别验证 Chrome/CloakBrowser 登录状态及实际 Cookie 解密。
3. 验证覆盖安装、用户数据保留、启动期间退出、单独关闭浏览器后的 HTTP 回退，以及退出启动器后自有进程全部结束。
4. 由用户在真实 BOSS 环境验证外发及平台提示；离线测试不验证平台兼容性或风控结果。

安装版需要重新构建安装包才能包含这些修复。本文记录源码验证结果，不代表已生成或验收 Windows 安装包。
